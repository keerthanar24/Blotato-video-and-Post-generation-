# Valuecart · Independence Day — 40s Video Package

A production-ready 40-second cinematic Independence Day film, built to be pasted straight into
the **HeyGen AI video creator prompt window**. Same structure as the AI Agent Building Challenge
package, different register: that film is neon and synthetic, this one is warm, physical and human.

> **Hard rule: no dates.** No day, month, year, or year-count is spoken, shown or generated.
> "Independence Day" identifies itself.

| File | What's in it |
|---|---|
| `01-scenario-and-brief.md` | Scenario, specs, tricolour + brand palette, flag-respect rules |
| `02-master-script.md` | Scene-by-scene script: visuals, VO, on-screen text, transitions, animations, plus an "invite" VO variant |
| `03-heygen-paste-ready.md` | **Start here.** Copy-paste blocks for HeyGen (16:9, 9:16, script-only, 15s greeting) |
| `04-ai-video-clip-prompts.md` | 11 AI B-roll clip prompts |
| `05-image-prompts.md` | 12 image prompts + placement notes |
| `06-production-checklist.md` | Build order, QA checklist, export settings, distribution copy |

**Fastest path:** open `03-heygen-paste-ready.md`, copy **Block A**, paste into HeyGen, generate.
