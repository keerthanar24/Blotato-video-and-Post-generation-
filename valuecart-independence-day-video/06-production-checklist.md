# Part 6 · Production Checklist & Delivery

### Build order (fastest path)
1. Paste **Block A** (`03-heygen-paste-ready.md`) into the HeyGen prompt window → generate draft.
2. Generate **IMG-02, 05, 06, 11** first — flag hero, title plate, Chakra, endcard carry the film.
3. Generate **CLIP 02, 08, 11** (the hoist, the Chakra spin, the endcard loop) — highest impact.
4. Swap in **real Valuecart celebration photos** for Scene 4 if you have any.
5. Type all copy as **HeyGen text layers**, never baked into images.
6. Add transitions per the map in `02-master-script.md`, then the music bed.
7. Export 16:9 → duplicate the project and re-run **Block C** for the 9:16 cut.

### Pre-export QA
- [ ] **No date, month, year or year-count** anywhere — spoken, on screen, in captions, or in an image
- [ ] Runtime **40.0s or under**
- [ ] Flag correct in every frame: **saffron on top**, never touching the ground, never worn, never distorted
- [ ] **Ashoka Chakra has exactly 24 spokes**, navy, correctly proportioned — count them
- [ ] No political imagery, party colours, military hardware or leader portraits
- [ ] No generated face is sharp enough to read as a specific "employee" who doesn't exist
- [ ] "जय हिंद · JAI HIND" renders correctly — Devanagari doesn't break or box out
- [ ] Anthem audio, if used, is respectful in mix and you have the rights to it
- [ ] Ends on the lit Valuecart logo — **no fade to black**
- [ ] Audio peaks ≤ −3 dBFS; VO sits ~8 dB above the music bed
