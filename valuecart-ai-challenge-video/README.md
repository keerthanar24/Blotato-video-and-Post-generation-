# Valuecart · AI Agent Building Challenge — 40s Video Package

A complete, production-ready 40-second internal announcement video kit, built to be pasted
straight into the **HeyGen AI video creator prompt window**.

> **Hard rule across this package: no dates.** No day, month, or year is spoken, shown, or
> generated anywhere. The video points people to "the new presentation schedule" instead.

| File | What's in it |
|---|---|
| `01-scenario-and-brief.md` | The scenario, video specs, brand color tokens, locked facts |
| `02-master-script.md` | Scene-by-scene script: visuals, VO, on-screen text, transitions, animations |
| `03-heygen-paste-ready.md` | **Start here.** Copy-paste blocks for HeyGen (16:9, 9:16, script-only, 15s teaser) |
| `04-ai-video-clip-prompts.md` | 9 AI B-roll clip prompts (Higgsfield / Veo / Runway / Kling / Sora) |
| `05-image-prompts.md` | 12 image prompts + placement notes |
| `06-production-checklist.md` | Build order, QA checklist, export settings, distribution copy |

**Fastest path:** open `03-heygen-paste-ready.md`, copy **Block A**, paste into HeyGen, generate.
